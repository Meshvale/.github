# Meshvale

Tools and libraries for working with 3D polygon meshes.

Meshvale is in early development. The repositories are initialized; software packages and supported-operation releases are forthcoming.

## Products

| Repository | Purpose |
|---|---|
| [meshvale-geometry](https://github.com/Meshvale/meshvale-geometry) | C++20 polygon mesh geometry and attributes |
| [meshvale-interchange](https://github.com/Meshvale/meshvale-interchange) | Asset import, export, and conversion reporting |
| [meshvale-repair](https://github.com/Meshvale/meshvale-repair) | Configurable mesh inspection and repair |
| [meshvale-simplify](https://github.com/Meshvale/meshvale-simplify) | Mesh reduction with stated preservation criteria |
| [meshvale-validate](https://github.com/Meshvale/meshvale-validate) | Asset checks, coverage, and validation reports |

Triangles, quads, n-gons, and mixed polygon meshes are a shared support goal. Format and operation coverage will be specified by each product as implementation becomes available.
